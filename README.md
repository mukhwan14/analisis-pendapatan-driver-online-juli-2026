# Analisis Pendapatan Driver Online — Juli 2026

## 📌 Overview

Project ini merupakan analisis sederhana terhadap data aktivitas dan pendapatan saya sebagai driver online selama Juli 2026.

Tujuan project ini adalah untuk memahami pola pendapatan harian, hubungan antara jumlah order dan pendapatan, serta melihat apakah terdapat perbedaan pendapatan berdasarkan hari dalam seminggu.

Project ini dibuat sebagai bagian dari proses pembelajaran dan pengembangan portfolio Data Analyst.

---

## 🎯 Business Questions

Beberapa pertanyaan yang ingin dijawab melalui analisis ini:

1. Apakah jumlah order berkaitan dengan pendapatan harian?
2. Apakah terdapat perbedaan pendapatan berdasarkan hari dalam seminggu?
3. Apakah jumlah order yang lebih banyak selalu menghasilkan pendapatan yang lebih tinggi?

---

## 📊 Dataset

Dataset terdiri dari 31 observasi harian selama Juli 2026.

Variabel yang digunakan:

| Column | Description |
|---|---|
| Tanggal | Tanggal aktivitas |
| Hari | Hari dalam seminggu |
| Jam Online | Total jam online dalam satu hari |
| Jumlah Order | Jumlah order yang diterima |
| Pendapatan | Total pendapatan harian |

---

## 🔍 Key Findings

### 1. Hubungan jumlah order dan pendapatan

Jumlah order menunjukkan kecenderungan hubungan positif dengan pendapatan. Namun, hubungan tersebut tidak sempurna.

Artinya, semakin banyak order secara umum berkaitan dengan pendapatan yang lebih tinggi, tetapi jumlah order bukan satu-satunya faktor yang berkaitan dengan pendapatan.

### 2. Perbedaan berdasarkan hari

Minggu memiliki rata-rata pendapatan tertinggi, sedangkan Jumat memiliki rata-rata pendapatan terendah selama periode pengamatan.

### 3. Jumlah order bukan satu-satunya faktor

Terdapat beberapa hari ketika jumlah order lebih sedikit tetapi pendapatannya lebih tinggi.

Hal ini menunjukkan bahwa karakteristik setiap order kemungkinan juga berperan dalam perbedaan pendapatan.

---

## ⚠️ Limitations

Analisis ini memiliki beberapa keterbatasan.

Dataset hanya mencakup satu bulan dan berasal dari aktivitas satu driver, sehingga hasilnya tidak dapat digunakan untuk menggambarkan kondisi seluruh driver online.

Selain itu, dataset belum memiliki beberapa variabel yang mungkin berkaitan dengan pendapatan, seperti:

- Jarak perjalanan
- Jenis layanan
- Kondisi cuaca
- Biaya bahan bakar
- Bonus atau insentif
- Lokasi pengambilan order

Oleh karena itu, hasil analisis ini lebih tepat digunakan untuk memahami pola pada data pribadi selama periode pengamatan.
